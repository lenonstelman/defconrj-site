DEFCON_GROUP(7) — DCG5521 Community Manual
NAME
defcon_group — comunidade local de hackers e profissionais de segurança da informação
SYNOPSIS
defcon_group [ --meetup ] [ --workshop ] [ --ctf ] [ --community ]
DESCRIPTION
DEF CON Groups são comunidades locais independentes, afiliadas à rede global DEF CON. Não somos empresa, não vendemos curso, não cobramos entrada. Reunimos hackers, profissionais de segurança, makers, estudantes e curiosos em espaços abertos para trocar ideia, ver demo ao vivo e hackear coisa junto.
OPTIONS
  • --meetup — Encontro mensal presencial. Palestra curta, demo ao vivo, mão na massa.
  • --workshop — Sessão prática com foco técnico. Lock picking, SDR, reversing.
  • --ctf — Competição de segurança ofensiva em formato jeopardy.
  • --community — Espaço aberto para networking sem hierarquia.
